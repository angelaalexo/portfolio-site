YouTube Similar Creators

A Python-based data analysis project that identifies similarities between YouTube channels using subscriber counts, video titles, and audience engagement — retrieved through the YouTube Data API and compared with TF-IDF and cosine similarity.

View on GitHub
// what I built

Finding the channels that behave alike

Recommendation and discovery on YouTube usually rely on the platform's own black-box algorithm. I wanted to see what a transparent, from-scratch version could look like: given a set of channels, which ones are actually similar — not by category label, but by what they publish and how their audience responds?

The project pulls channel and video data directly through the YouTube Data API, processes it into comparable features, and scores every channel pair using TF-IDF over video titles combined with cosine similarity — surfacing a ranked list of the most similar creators to any channel in the set.
