Fashion ID

A computer vision project that detects fashion brand logos in images using object detection. Built with Python and YOLO, the project explores how machine learning can transform visual fashion content into identifiable brand information.

View on GitHub
// what I built

Teaching a model to recognize fashion brands

Fashion imagery contains a huge amount of visual information, but identifying the brands appearing in an image is often something that still requires manual recognition. Fashion ID explores how computer vision can automate that process by detecting recognizable fashion logos directly from images.

The project uses a YOLO-based object detection pipeline to locate fashion logos within an image and identify the detected brand. I worked with a large logo dataset, prepared the annotations for training, and built the processing pipeline needed to turn raw image data into a format suitable for machine learning.

The result is a foundation for an image-based fashion recognition system: provide an image, run the trained model, and receive predictions showing where recognizable brand logos appear.
